Sobre o curso

Do Zero ao Portfólio Web é um curso para quem nunca escreveu uma linha de código e quer sair do zero com um resultado visível. Cada módulo termina com uma entrega prática.

O conteúdo segue a lógica Mobile First: você aprende primeiro a montar o layout do celular e depois a adaptá-lo para telas maiores, do jeito que o mercado faz hoje.
