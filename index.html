Praticando 1 - Tabelas com dados reais

Praticando 1 - Nesta atividade você vai praticar tags como <table>, <caption> e <th scope="col"> para estruturar dados de forma semântica.

Praticando 2 - Aqui você vai praticar os atributos <td colspan="4"> e <td rowspan="4">, usados para mesclar células e criar tabelas mais complexas.

Praticando 3 - Receita de bolo com listas

Praticando 3 - Nesta página você vai praticar listas usando as tags <ul> (não ordenada) e <ol> (ordenada), organizando os ingredientes e o modo de preparo de uma receita.
